## این برنامه چه کاری می‌کند؟

AARK Kernel یک **داشبورد معاملات و مدیریت ریسک** است. سه کار اصلی انجام می‌دهد:

### ۱. نشان دادن بازار، زنده

قیمت‌ها را هر چند ثانیه به‌روز می‌کند و روی نمودار نشان می‌دهد. دفتر سفارشات
(Order Book) هم به‌صورت زنده به‌روز می‌شود.

### ۲. محاسبهٔ ریسک — قبل از اینکه پول در خطر کنید

این مهم‌ترین بخش است. موتور ریسک به شما می‌گوید:

| پرسش شما | پاسخ برنامه |
|---|---|
| «اگر فردا بازار ۵٪ بیفتد، چقدر ضرر می‌کنم؟» | مقدار دقیق ضرر |
| «بدترین حالت محتمل چیست؟» | ۶ سناریوی استرس: سقوط شدید، زمستان کریپتو، سقوط ناگهانی و… |
| «چقدر از پولم روی یک دارایی متمرکز شده؟» | شاخص تمرکز HHI |
| «برای این معامله چند واحد بخرم؟» | سایز پوزیشن پیشنهادی بر اساس نوسان |

### ۳. نگهداری امن کلید صرافی

کلید API نوبیتکس را در یک **گاوصندوق جدا** نگه می‌دارد: پوشهٔ قفل‌شده
(`0700`) و فایل قفل‌شده (`0600`). این کلید **در دیتابیس ذخیره نمی‌شود**، پس
حتی اگر دیتابیس لو رفت، کلید شما در امان است.

## نصب گام‌به‌گام

### گام ۱ — دریافت برنامه

ترمینال (ویندوز: PowerShell یا Command Prompt) را باز کنید:

```bash
git clone https://github.com/ansariaiadmin/aark-kernel.git
cd aark-kernel
```

### گام ۲ — اجرای جادوگر نصب

```bash
chmod +x install.sh
./install.sh
```

**این دستور چه می‌پرسد؟**

```
📧 ایمیل ادمین:        admin@aark-kernel.dev
🔑 رمز ادمین:          **************     (حداقل ۱۲ کاراکتر)
```

**و خودش چه می‌کند؟**

1. Docker را بررسی می‌کند
2. فایل تنظیمات `.env` را با رمزهای تصادفی و قوی می‌سازد
3. پایگاه داده PostgreSQL و حافظهٔ موقت Redis را بالا می‌آورد
4. بک‌اند و داشبورد را می‌سازد و اجرا می‌کند
5. **حساب ادمین شما را واقعاً در دیتابیس می‌سازد** تا بتوانید وارد شوید

⏱ معمولاً ۲ تا ۴ دقیقه طول می‌کشد (بسته به سرعت اینترنت).

### گام ۳ — ورود

مرورگر را باز کنید و بروید به:

```
http://localhost:3000
```

با همان ایمیل و رمزی که در گام ۲ وارد کردید، وارد شوید.

> **اگر صفحهٔ سفید دیدید:** چند ثانیه صبر کنید و صفحه را refresh کنید. داشبورد
> برای اولین بار در حال آماده‌شدن است.

## گردشی در داشبورد

بعد از ورود، این بخش‌ها را می‌بینید:

| بخش | چه می‌بینید | چه کاری می‌توانید بکنید |
|---|---|---|
| **نوار بالا** | نام شما، نقش شما، دکمهٔ خروج | خروج از حساب |
| **کارت‌های خلاصه** | ارزش کل پورتفولیو، سود/زیان روز، تعداد پوزیشن | — |
| **نمودار قیمت** | خط زندهٔ قیمت | تغییر بازهٔ زمانی |
| **تب‌ها** | پورتفولیو · سفارشات · ریسک · ایجنت | جابه‌جایی بین بخش‌ها |
| **دفتر سفارشات** | بهترین قیمت‌های خرید و فروش | مشاهدهٔ زنده |
| **کلید قطع اضطراری** | دکمهٔ قرمز «Kill Switch» | متوقف کردن همهٔ عملیات |

### تب ریسک — مهم‌ترین تب

در این تب می‌توانید:

- **روش VaR** را انتخاب کنید: تاریخی، پارامتریک یا مونت‌کارلو
- **ارزش پورتفولیو** را وارد کنید
- نتیجه را ببینید: «با اطمینان ۹۵٪، بیشترین ضرر شما X است»

> **توضیح سادهٔ VaR:** VaR یعنی «بیشترین پولی که با احتمال ۹۵٪ از دست می‌دهید».
> اگر VaR شما ۱۰۰ هزار تومان باشد، یعنی فقط در ۵٪ مواقع ضررتان بیشتر از
> ۱۰۰ هزار تومان می‌شود.

### کلید قطع اضطراری (Kill Switch)

دکمهٔ قرمز در نوار بالا. با فشردن آن:

1. همهٔ سفارش‌های در انتظار لغو می‌شوند
2. هیچ سفارش جدیدی ثبت نمی‌شود
3. وضعیت روی صفحه و در لاگ ثبت می‌شود

## کارهای روزمره

| می‌خواهم… | دستور |
|---|---|
| برنامه را روشن کنم | `./start.sh` |
| برنامه را خاموش کنم | `./stop.sh` |
| ببینم چه خبر است | `./status.sh` |
| لاگ بک‌اند را ببینم | `./logs.sh backend` |
| از تنظیماتم بکاپ بگیرم | `./backup.sh` |
| برنامه را به‌روز کنم | `./update.sh` |
| تست کنم که همه‌چیز سالم است | `./smoke-test.sh` |

> روی ویندوز، همان دستورها با پسوند `.bat` کار می‌کنند: `start.bat`، `status.bat` و…

## ایمن‌سازی

### چیزهایی که حتماً انجام دهید

| # | کار | چرا |
|---|---|---|
| ۱ | رمز ادمین قوی بگذارید (حداقل ۱۲ کاراکتر، ترکیب حرف و عدد) | جلوگیری از حدس زدن |
| ۲ | فایل `.env` را محرمانه نگه دارید: `chmod 600 .env` | همهٔ رازهای شما در آن است |
| ۳ | فایل `.env` را هیچ‌وقت در git قرار ندهید | از قبل در `.gitignore` هست |
| ۴ | از بکاپ رمزنگاری‌شده (`./backup.sh`) استفاده کنید | اگر دیسک شما خراب شد |

### چیزهایی که هرگز نکنید

- ❌ کلید API صرافی را در کپی‌پیست عمومی نگذارید
- ❌ رمز را در اسکرین‌شات بفرستید
- ❌ بک‌اند را مستقیماً روی اینترنت باز کنید بدون reverse proxy با احراز هویت

## عیب‌یابی

### «صفحه باز نمی‌شود»

```bash
./status.sh          # کدام سرویس خاموش است؟
./logs.sh            # خطا را ببینید
```

رایج‌ترین علت: Docker Desktop اجرا نیست. آن را روشن کنید و دوباره
`./start.sh` بزنید.

### «نمی‌توانم وارد شوم»

**علت ۱:** رمز را اشتباه می‌زنید. یادداشت کنید که رمز حساس به حروف بزرگ و کوچک است.

**علت ۲:** حساب ادمین ساخته نشده. بررسی کنید:

```bash
docker compose logs backend | grep -i "bootstrap"
```

باید خطی شبیه این ببینید: `Bootstrap admin created: admin@...`
اگر نبودید، این دو خط را در `.env` بگذارید و `./update.sh` بزنید:

```
ADMIN_EMAIL=admin@aark-kernel.dev
ADMIN_PASSWORD=<رمز-قوی-۱۲-کاراکتری>
```

### «پورت اشغال است»

```bash
./stop.sh
# در ویندوز: netstat -ano | findstr :3000
# در لینوکس/مک: lsof -i :3000
./start.sh
```

### «خطای ۴۰۱ Unauthorized»

یعنی توکن شما منقضی شده (۳۰ دقیقه). دوباره وارد شوید. این رفتار عمدی و امنیتی است.

### «خطای ۵۰۰ روی صفحهٔ ریسک»

اول لاگ بک‌اند را ببینید: `./logs.sh backend`. اگر خطا مربوط به Ollama بود،
یعنی مدل زبانی در دسترس نیست — بقیهٔ داشبورد کار می‌کند.

## پرسش‌های پرتکرار

**پول واقعی خرج می‌شود؟**
خیر. در این نسخه، بخش معاملات روی **حالت آزمایشی (Paper Trading)** کار می‌کند:
سفارش شبیه‌سازی می‌شود و هیچ پول واقعی جابه‌جا نمی‌شود.

**داده‌هایم کجا ذخیره می‌شود؟**
روی کامپیوتر خودتان. پایگاه داده PostgreSQL و کیف کلیدها هر دو محلی‌اند. هیچ
داده‌ای به سرور بیرون ارسال نمی‌شود.

**می‌توانم روی موبایل استفاده کنم؟**
بله. برنامه PWA است: در مرورگر موبایل گزینهٔ «Add to Home Screen» را بزنید تا
مثل یک اپلیکیشن نصب شود.

**چند کاربر می‌تواند هم‌زمان استفاده کند؟**
چند نفر. نقش‌ها: **Admin** (مدیر کامل)، **Trader** (معامله)، **Viewer** (فقط
مشاهده). Admin می‌تواند از `POST /api/v1/auth/register` کاربر بسازد.

**چطور کلید API نوبیتکس را وارد کنم؟**
از تب تنظیمات، endpoint مربوطه را صدا بزنید. کلید در کیف امن (`~/.aark`)
با مجوز `0600` نوشته می‌شود.

> ⚠️ **توجه امنیتی:** endpoint ذخیرهٔ کلید در نسخهٔ 3.3.0 هنوز نیاز به توکن
> ندارد. تا رفع این مورد در نسخهٔ 3.4.0، بک‌اند را فقط روی شبکهٔ محلی
> (`127.0.0.1`) یا پشت reverse proxy با احراز هویت اجرا کنید.
